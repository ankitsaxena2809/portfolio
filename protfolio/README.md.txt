# Ankit Saxena - Portfolio

## Files
- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — mobile menu and year
- `resume.pdf` — add your real resume here

## Before publishing
1. Replace `your.email@example.com` with your email.
2. Replace the GitHub and LinkedIn links with your profiles.
3. Replace project `#` links with real GitHub/demo URLs.
4. Put your resume PDF in this folder and name it `resume.pdf`.
5. Upload the folder to GitHub and enable GitHub Pages.

## GitHub Pages
Create a repository, upload these files, then go to:
Settings → Pages → Deploy from branch → main → /(root)
